Explain [OOP concept, e.g. polymorphism] using a diagram and technical
explanatory writing.

Diagram:
- Draw it as a memory/structure diagram (like Stack, Heap, Class area)
  with numbered steps showing what happens at runtime.
- Use generic names such as Class A, Class B, Object A, method, Variable (never use the word field) and
  reference (never use the word address). Do not use real-world examples like Car or Engine.
- Keep labels short. Put the explanation in the text, not inside the boxes.

Writing:
- Use a technical explanatory style: introduction, step-by-step
  explanation matching the diagram numbers, key concepts, and a
  failure case or common mistake.
- Do not include any code.
- Use terms like method, reference, object, class, field, and instance.
